# Leitor de CSV

Visualizador e editor de arquivos CSV em um único HTML. Não usa dependências, servidor ou envio de arquivos: tudo roda no navegador.

## Usar

Abra `index.html` no navegador ou publique o repositório no GitHub Pages. Use **Abrir CSVs** para escolher um ou mais arquivos, ou **Carregar pasta** para carregar vários CSVs de uma pasta em navegadores com suporte ao seletor de diretório.

O leitor reconhece separadores por vírgula, ponto e vírgula, tabulação e barra vertical. Edite células, filtre, ordene, redimensione ou reorganize colunas. **Baixar CSV** exporta o arquivo ativo e mantém o separador detectado.

As alterações feitas em arquivos abertos no GitHub Pages ficam no armazenamento local do navegador e não alteram o arquivo original. Baixe o CSV para salvar uma cópia editada. Ao abrir `index.html` diretamente do disco ou carregar uma pasta, as alterações duram apenas na sessão até serem baixadas.
